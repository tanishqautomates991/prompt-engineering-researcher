# Prompt Engineering Researcher
**Author:** Tanishq Soni
**Loom Video URL:** [https://www.loom.com/share/prompt-engineering-researcher-walkthrough](https://www.loom.com/share/prompt-engineering-researcher-walkthrough)

This repository contains an AI-assisted research workflow applying Generated Knowledge Prompting, CoVe (Chain of Verification), and the ERA framework to compare Kubernetes, Docker Swarm, and AWS Fargate.

## Repository Contents
- `README.md`: Project overview, author details, and Loom presentation link.
- `comparison_matrix.md`: Standardized 5-column technical evaluation matrix.
- `executive_summary.md`: Strict 150-word executive summary and technology recommendation.
- `prompt_documentation.md`: Parameterized prompt templates for Generated Knowledge, ERA baseline drafting, 3-step CoVe cycle, and Assumption Audit.
- `research_report.md`: Complete research audit trail featuring the background fact sheet, baseline draft, 4 verification questions, verified documentation answers, explicit correction mapping, final verified report, and assumption audit.
