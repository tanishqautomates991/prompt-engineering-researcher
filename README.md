# Prompt Engineering Researcher
**Author:** Tanishq Soni

**Knowledge & Data Currency Boundary:** September 2026

This repository contains an AI-assisted research workflow applying Generated Knowledge Prompting, CoVe (Chain of Verification), and the ERA framework to compare Kubernetes, Docker Swarm, and AWS Fargate under an explicit September 2026 knowledge and data currency boundary.

## Repository Contents
- `README.md`: Project overview, author details, data boundary, and Loom presentation link.
- `comparison_matrix.md`: Standardized 5-column technical evaluation matrix with qualified autoscaling metrics.
- `executive_summary.md`: Strict 150-word executive summary and technology recommendation.
- `prompt_documentation.md`: Parameterized prompt templates for Generated Knowledge, ERA baseline drafting, 3-step CoVe cycle, and Assumption Audit with explicit September 2026 boundary parameters.
- `research_report.md`: Complete research audit trail featuring the background fact sheet, baseline draft, 4 verification questions, verified documentation answers with strengthened source references, explicit correction mapping, final verified report, and assumption audit.
